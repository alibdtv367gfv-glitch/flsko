# قائمة إطلاق Flsko على Google Play

هذه النسخة ترفع جاهزية المشروع تقنيًا، لكنها لا تُعد نشرًا نهائيًا بحد ذاتها. ما يزال النشر يحتاج حساب Play Console، توقيع Android App Bundle، رابط سياسة خصوصية عام، تعبئة Data safety، واختبارات على أجهزة حقيقية.

| المجال | حالة المشروع | ما يلزم قبل الإرسال |
|---|---|---|
| اسم التطبيق | مكتمل: Flsko | مراجعة الاسم والوصف واللقطات في Play Console |
| الشعار | مكتمل: شعار روبوت PNG شفاف، مرتبط بأيقونة التطبيق وواجهة البداية | تجهيز أيقونة 512×512 ومواد المتجر النهائية إذا طلب Play Console مقاسات مختلفة |
| معرف Android | `com.flsko.app` | عدم تغييره بعد أول نشر عام |
| رقم الإصدار | `1.0.1` و`versionCode: 2` | رفع `versionCode` مع كل تحديث |
| target API | مضبوط على API 36 في إعداد Expo | تأكيد نتيجة البناء النهائية وفق متطلب Google Play الساري يوم الرفع |
| الخصوصية | صفحة داخلية ومسودة سياسة موجودة | نشرها على رابط HTTPS عام وإضافة بيانات الجهة المالكة ومدة الاحتفاظ ووسيلة التواصل |
| Data safety | البيانات التي تحتاج الإفصاح: الحساب، الرسائل، الملفات والذاكرة التي يختار المستخدم حفظها | تعبئة النموذج بدقة بعد تثبيت مزودي السحابة النهائيين |
| حذف الحساب | الذاكرة قابلة للمراجعة والحذف | إضافة تدفق حذف الحساب وطلب الحذف السحابي قبل الإطلاق العام |
| محتوى الذكاء الاصطناعي | زر إبلاغ للحوار ونتائج الصور والفيديو وجدول `content_reports` | ربط البلاغات بلوحة مراجعة وإجراء زمني للمعالجة |
| المصادر المفتوحة | مقارنة إجابات Gemini وChatGPT والمزودات المفتوحة، مع Wikipedia العربية كقناة بحث احتياطية | ربط مزود بحث مفتوح موثوق وإضافة سياسات حقوق النشر والاقتباس |
| أمان الخادم | الأسرار على الخادم، لا داخل الهاتف | إضافة rate limiting وWAF ومراقبة الأخطاء ونسخ احتياطي واختبار اختراق مستقل |
| تجربة الوسائط | مشغلات صوت وفيديو مدمجة مع دعم ملء الشاشة للفيديو | اختبار التشغيل على أجهزة Android حقيقية واتصالات بطيئة |
| تجربة المقارنة | مراحل عامة متحركة: الفهم، جمع المعرفة، الموازنة، الصياغة | اختبار حالات timeout والفشل والتبديل بين الشبكات |
| المحتوى السوري | طبقة منظمة للتنوع واللهجات ونبرة الحوار، مع رفض التنميط والتخمين الحساس | بناء لوحة مراجعة لمصادر الثقافة العامة وتصنيفها بالمحافظة والموضوع والمصدر |

## تنبيه مهم

يستخدم Flsko سياق الحوار الأخير لتثبيت اللهجة والأسلوب، ويحفظ الذاكرة الدائمة فقط بعد موافقة المستخدم. هذا يحقق تعلّمًا شخصيًا قابلًا للتحكم، وليس تدريبًا خفيًا على جميع المستخدمين. يجب إبقاء هذا الفرق واضحًا في سياسة الخصوصية ووصف التطبيق.

## مراجع رسمية

راجِع [سياسة بيانات المستخدم](https://support.google.com/googleplay/android-developer/answer/10144311)، و[نموذج Data safety](https://support.google.com/googleplay/android-developer/answer/10787469)، و[سياسة المحتوى المولّد بالذكاء الاصطناعي](https://support.google.com/googleplay/android-developer/answer/13985936)، و[سياسة المحتوى الذي ينشئه المستخدمون](https://support.google.com/googleplay/android-developer/answer/9876937)، و[متطلب target API](https://developer.android.com/google/play/requirements/target-sdk) قبل الرفع.
